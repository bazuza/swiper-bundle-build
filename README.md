# swiper-bundle-build

Swiper v11 - MIT License - https://swiperjs.com/

## ⚙️ Tools:
`node --version >= v18`

`npm --version >= v10`

`yarn --version 1.22.19`

## 🛠️ Install:

`npm install`

`yarn install`

## 🛠️ Simple build:

`npx rollup -c`

You can add modules (for example: Autoplay, Controller... etc.)
